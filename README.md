# Profile Card (Tailwind CSS)

A responsive profile card built with HTML and Tailwind CSS v4. This is the first
project in my front-end practice series, where I rebuild simple UI designs to
learn styling fundamentals.

## What I practiced

- Centering a card with Flexbox (`flex`, `justify-center`, `items-center`)
- Full-height layout with `min-h-screen`
- Responsive card width with `w-full max-w-xs`
- Circular avatar with `size-20`, `rounded-full` and `mx-auto`
- Box model and depth: padding, `rounded-xl`, outline and `shadow-xl`
- Typography hierarchy using size, weight and color
- Divider lines with `hr`
- Equal-width buttons with `flex-1`
- Hover effects with `transition`, `hover:` and `cursor-pointer`
- Balanced text wrapping with `text-balance`

## Run it

No install needed. Open `index.html` in your browser. Tailwind loads from a CDN.

## Tech

HTML5, Tailwind CSS v4 (browser CDN)
